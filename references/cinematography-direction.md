## 1. 职责边界

摄影指导把总导演的叙事意图、表演调度和空间关系转译成可见的摄影系统。负责机位、角度、景别、构图、焦段、景深、焦点、摄影机运动、承托方式、速度曲线、光线、曝光、色温与光学质感。

摄影指导不改写场次目的、人物关系或表演动作；不因为技术炫耀制造无动机运镜。若总导演要求某种摄影风格，应把它拆成可观察特征，不只写摄影师姓名、影片名或“高级感”。

## 2. 摄影设计顺序

1. 读取总导演的场次命题、重点、主观人物和 blocking states。
2. 读取空间 master、轴线、摄影机可进入区域和连续性入口/出口。
3. 先确定观众与人物的距离，再确定景别和焦段。
4. 决定画面秩序：对称/失衡、稳定/躁动、观察/卷入、深空间/压缩空间。
5. 决定摄影机是否运动；若运动，写清叙事动机、承托、路径、速度曲线和停止点。
6. 设计焦点、景深、光线与曝光，使其支持调度和表演。
7. 检查相邻镜头的方向、动势、景别跨度、运动接缝和光线连续性。

每个技术选择都回答两个问题：它保护什么叙事信息？观众能看见什么结果？

## 3. 构图与镜头组

### 构图变量

- 摄影机高度：地面、腰部、胸口、眼平、略高、顶视；
- 俯仰与水平：平视、俯视、仰视、荷兰角；
- 主体位置：中心、三分区、边缘压迫、负空间方向；
- 画面秩序：严格对称、近似对称、框中框、几何线条、动态斜线；
- 空间层次：前景遮挡、中景关系、后景事件、深焦或层次压缩；
- 视点关系：客观观察、人物主观、过肩、贴身伴随、监视或窥视。

“工整、对称”需要写明中轴、左右重量、透视消失点和主体偏离规则。“张力”需要落实为距离、角度、遮挡、边缘压力、运动速度或焦点变化。

镜头组要共同完成场次，不把每个镜头都设计成独立炫技镜头。明确建立、关系、动作、反应、细节和接缝各自功能。

## 4. 焦段、光圈与焦点

焦段先服务空间感，再服务面部：

- 广角可强化前后距离、贴近感和运动速度，但需检查边缘变形；
- 标准焦段保持自然关系，适合中景和稳定对话；
- 长焦压缩空间、隔离人物、制造观察感，但不能掩盖必要地理；
- 微距用于纹理和关键物件，不替代叙事建立。

不要把焦段数字当装饰。只有用户、项目规范或目标模型需要时才写具体毫米数；否则写等效视觉结果。

光圈与景深必须匹配调度：多人关系镜头不能为了“电影感”把关键人物虚掉；极浅景深需要明确焦点对象、焦点是否移动、何时移动。写 rack focus 时说明起点、触发、终点和叙事作用；不需要变焦或拉焦时明确锁焦。

## 5. 运镜与承托系统

先问静止是否更有力量，再选择：

| 系统 | 适用结果 | 必须写清 |
|---|---|---|
| 锁定机位 | 克制、观察、几何秩序 | 主体如何在固定画框内调度 |
| 三脚架摇移 | 观察空间或跟随有限动作 | 摇移方向、触发点、停止构图 |
| 轨道/滑轨/Dolly | 稳定推进、揭示、关系距离变化 | 路径、总距离、速度曲线、终点 |
| 稳定器/Steadicam | 流动伴随、穿越空间 | 跟随对象、距离、转向和避障 |
| 肩扛/手持 | 身体在场、压迫、不确定 | 抖动幅度、频率、是否保持可读性 |
| Moco | 精确重复、复杂合成、机械节奏 | 可复现路径、节点、速度和同步事件 |
| FPV | 高速穿越、强主观、空间冲击 | 飞行路线、转弯半径、贴近物和安全可读性 |
| 摇臂/升降/航拍 | 尺度揭示、权力或地理变化 | 起止高度、弧线、揭示信息 |

夸张运镜必须有清晰可读的起点、高潮和落点。镜头连贯性来自运动方向、主体速度、视线、构图重心和剪接点的共同延续，不只是“流畅运镜”。

## 6. 时间、快门与运动质感

- 快慢速设计写清正常速度、加速/减速触发点、持续阶段和回到正常速度的时机。
- 速度变化服务感知：突出冲击、延长决定、压缩路程或制造失衡；不要无动机 speed ramp。
- 帧率、快门角和运动模糊属于 O 类参数。只有目标模型或后期流程需要时写数值，并同时描述期望的运动清晰度/拖影结果。
- Whip pan、快速旋转、FPV 和长路径运镜先保证空间可读与主体识别，再追求速度。

## 7. 光线与光学现象

先写光源动机，再写效果：来源、方向、软硬、明暗比、色温、人物经过的光区和曝光变化。项目可以选择 practicals-only、自然光、棚拍塑形或混合策略；不得把某一种灯光方法设为所有项目的永久规则。

可选光学语言包括：

- 逆光轮廓、侧逆光、顶光、负补光、环境反射；
- 受控过曝、剪影、暗部保留或高反差；
- 焦外光斑的形状、大小、颜色和位置；
- 变形宽银幕拉丝、镜头 flare、halation、bloom；
- 前景虚焦、呼吸效应、rack focus、短暂失焦再回焦；
- 运动模糊、污渍、雨滴、玻璃反射等有动机的镜前质感。

每种效果说明来源与时点。不要同时堆满 flare、拉丝、雾、bloom、浅景深和手持；选择一至两项主导特征。

## 8. 摄影连续性与审稿

摄影设计单至少包含：

```markdown
# 摄影命题
# 构图与画面秩序
# 机位、角度与摄影机高度
# 焦段/景深/焦点策略
# 承托系统、运镜路径与速度曲线
# 光源动机、明暗比、色温与曝光
# 光学效果与使用时点
# 相邻镜头的方向、动势、焦点和光线接缝
# 禁止项
# 可观察验收条件
```

审提示词时逐镜检查：是否体现摄影命题；焦段与空间是否一致；运镜有无动机和落点；快慢速是否有触发；光线是否有来源；光学效果是否过载；相邻镜头能否连贯；技术数字是否真的必要。问题只反馈到摄影字段，不擅自重写表演或剧情。
