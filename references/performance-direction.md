## 1. 研究依据与转译边界

本方法综合以下公开资料的可执行共识，不要求机械套用某一表演流派：

- [Atlantic Acting School：Script Analysis](https://atlanticactingschool.org/courses/script-analysis/)：从既定情境出发，以清晰、可执行的动作和目标分析场景。
- [Meisner Institute：Actor Training](https://www.meisnerinstitute.com/actor-training)：强调真实地做、把注意力放在对手身上、逐刻回应刺激。
- [RADA BA Acting Programme Specification](https://www.rada.ac.uk/documents/1176/BA_Acting_Programme_Specification_May_2024.pdf)：把文本、身体、声音和角色反应整合为可持续的具身表演。
- [Runway Gen-4 Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)：提示词优先描述主体、摄影机和环境的具体运动，使用直接、正向、简单的表述，并通过逐项增加细节迭代。
- [Google Cloud Veo 提示指南](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/video/video-gen-prompt-guide?hl=zh-CN)：把提示拆为主体、动作、场景、机位、运镜、视觉与声音等可控元素。
- [Runway Performance Capture with Act-Two](https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two)：需要精确表演时，可将驱动表演视频作为动作、手势、表情和语音节奏的来源，而非只靠文字形容。

这些资料提供方法启发，不代表所有模型行为相同。模型、版本、参数和表现差异属于 O 类知识，必须通过本项目样本复测。

## 2. 表演分析骨架

每个 Beat 先写八项，再谈“情绪”：

1. **既定情境**：此刻人物知道什么、不知道什么、刚经历什么。
2. **目标**：人物想让对手做什么，写成“让他/她……”而不是“我很……”。
3. **阻力**：对手、环境、身份、秘密或身体条件怎样阻止目标。
4. **可演动作**：用主动动词，如试探、安抚、逼迫、诱导、掩饰、拒绝、拖延、夺回。
5. **注意对象**：目光、听觉和行动真正落在谁或什么上。
6. **刺激**：哪个词、声音、动作或物件状态触发变化。
7. **调整**：人物接收刺激后，策略、呼吸、重心或语气怎样改变。
8. **退出状态**：给下一镜继承的可观察状态。

优先写关系动作：“用轻描淡写迫使对方暴露恐惧”，不要写结果表情：“神秘而紧张地微笑”。一个 Beat 只保留一个主要行动，转变点再换动作。

## 3. 微表演谱

### 刺激—调整—动作—余波

微表演按时间链安排，避免所有部位同时启动：

```text
看见/听见刺激
→ 眼神或呼吸先产生最小调整
→ 身体任务被中断或改变
→ 台词/动作作为策略出现
→ 句后留下余波与新状态
```

每个 Beat 从以下通道中选择 2—4 个，不能全部堆满：

| 通道 | 可执行变量 |
|---|---|
| 目光 | 落点、停留、移开原因、眨眼频率、是否先看物再看人 |
| 呼吸 | 深浅、是否屏息、吐气点、台词前后气口 |
| 面部 | 下颌、嘴角、眉间、眼睑的单一细微变化 |
| 重心 | 前倾/后撤、脚下迟疑、肩背开合、是否保留逃离方向 |
| 手部任务 | 握、松、折、擦、整理、停住、继续完成真实物理任务 |
| 声音 | 音量、速度、音高范围、声线支撑、句尾、重音和吞字 |
| 时值 | 刺激后延迟、停顿长度、动作是否跨过台词 |

微表演不是“越细越多”。关键是刺激与变化有因果，非关键通道保持稳定，使观众能看见那一次变化。

### 表演谱模板

| Beat | 刺激 | 目标/阻力 | 可演动作 | 注意对象 | 目光/呼吸 | 身体或手部任务 | 台词动作/语气 | 反应延迟 | 退出状态 | 禁用套路 |
|---|---|---|---|---|---|---|---|---|---|---|

## 4. 台词与声音

- 先确定台词在“对谁做事”，再确定语气；无对象的漂亮念白容易产生 AI 播报感。
- 重音服务策略变化，不按标点平均分配；一句话通常只保一个核心重音。
- 停顿必须有行为：观察对方、压住冲动、寻找借口、重新组织攻击，而非机械停顿。
- 允许动作跨过台词：说话时继续倒水、折纸、擦伤口或寻找出口，让“真实地做”承载情绪。
- 对话反应应落在对手刺激之后；避免角色提前知道下一句并预先摆好表情。
- 句尾可通过收声、抛给对方、突然截断或恢复手头任务体现关系，不必每句都完整落地。
- 多人对白明确发言人、听者、旁观者和每个人的反应时差。

若用户有可用的表演驱动视频、干净语音或动作参考，优先把它指定为表演来源；文字提示只补充参考中没有的空间、镜头、环境和连续性信息。

## 5. 去 AI 感诊断

| 症状 | 常见根因 | 改法 |
|---|---|---|
| 眉眼嘴同时夸张变化 | 用情绪结果词驱动全部通道 | 只指定一个首发通道和一个后续动作 |
| 每句都点头、摊手、抿嘴 | 无真实身体任务，模型调用通用手势 | 分配持续物理任务并写明何时中断 |
| 角色像背稿或播报 | 台词无对象、无目标、重音平均 | 写清对谁做什么，标刺激词与策略词 |
| 反应早于刺激 | 时间链未写或片段拼接错误 | 明确“听见/看见后，短暂停顿，再……” |
| 眼神漂浮 | 没有具体目光落点 | 用左侧门把、桌上信封、对手右眼等空间锚点 |
| 情绪一开始就满格 | 缺进入状态和升级台阶 | 用 2—3 个 Beat 逐步改变呼吸、重心和声音 |
| 角色全程“保持某情绪” | 没有目标和阻力 | 换成连续行动与策略转变 |
| 身体与声音不同步 | 提示冲突或动作过载 | 减少通道，每次只保主要动作与一个声音变化 |
| 两人同频表演 | 没有主次和反应时差 | 一人行动、一人接收，再交换主动权 |

## 6. 交付给提示词导演

按以下顺序，把表演谱压成短、正向、可见的字段，交由提示词导演合并；表演指导不单独覆盖摄影、群戏或连续性字段：

```markdown
[人物与位置]
谁在画面哪一侧，面对谁，正在做什么真实任务。

[刺激与时间链]
当什么发生后，谁先停顿/看向哪里，再做什么。

[主要可演动作]
角色用什么动作对对手达成什么，不写抽象心情。

[微行为]
选择少量目光、呼吸、重心、手部和声音变化。

[摄影机与环境]
镜头是否锁定/跟随；环境怎样保持生活。

[退出状态]
镜头结束时的位置、视线、持物和表演强度。
```

编译规则：

- 使用清楚的主体标识和位置关系；多人时逐人写动作。
- 优先正向描述希望发生什么，如“摄影机保持锁定”，不要反复写否定句。
- 从最关键的主体动作开始，确认成立后一次增加一个变量，以便归因。
- 输入图已确定外貌、构图和光线时，文本重点写运动与时间关系，不重新描述全部视觉。
- 抽象气质可以作为最后的弱风格限定，不能替代行为。
- 若文字难以精确控制复杂口型、手势或表演节奏，转用表演驱动、拆镜或反应镜头，不无限加词。

## 7. 表演审片与返工

按以下顺序看：

1. 观众是否看得出人物对谁做什么；
2. 反应是否由可见/可听刺激触发；
3. 关键转折是否有时间发生；
4. 目光、呼吸、重心、手部和声音是否因果一致；
5. 进入/退出状态是否可与相邻镜头剪接；
6. 是否有可保留的真实瞬间。

返工时先保表演成立区间。优先剪掉假动作、插反应、插手部/道具、补刺激或只重做一个 Beat；只有人物目标或整段策略错误时才重做整场表演。
