# 导演语法：从剧本到可见场面

## 目录

1. 场次目的与戏剧节拍

## 1. 场次目的与戏剧节拍

开始任何镜头设计前，先回答：

- 观众在本场新知道什么？
- 人物关系或力量对比发生什么变化？
- 情绪从哪里到哪里？
- 哪个瞬间必须被观众真正感受到，而不只是听到？

将这些答案压成一句导演命题。例如：“表面是交代任务，真正要拍的是新人第一次意识到规则残酷，并决定隐藏恐惧。”若命题不清，AI 容易把所有对白同速完成。

按戏剧力量变化拆 Beat：进入、试探、揭示、反应、选择、余波。一个 Beat 至少包含事件、人物目标、阻力、情绪状态和必须看见的行为。不要把任何固定生成时长当作戏剧单位；时长只是项目参数。

重要信息需要观众反应时间。信息揭示后至少设计一种可感知的承接：停顿、目光、呼吸变化、他人反应、环境静默或动作中断。

## 2. 情绪弧与表演动作

为每个 Beat 写清：

- 进入状态；
- 触发点；
- 身体或注意力变化；
- 退出状态。

把抽象词改写为可表演动作：

| 抽象词 | 可见行为示例 |
|---|---|
| 紧张 | 擦手、搓指、拧钥匙时微抖、呼吸变浅、目光寻找出口 |
| 隐瞒 | 回答前停顿、避开目光、先做无关动作、句尾收声 |
| 权力感 | 不急于回答、让别人等、少动作、先观察再开口 |
| 崩溃后平静 | 呼吸逐渐下降、身体收回、目光重新聚焦、语速变慢 |
| 警觉 | 进门前停步、先扫视空间、身体保持撤退方向 |

表演至少检查六层：人物目标、注意力、节奏、身体重心、微动作、反应。不要用“更有戏”“更电影感”代替动作指令。

反应镜头同时承担四种功能：证明人物听懂、给观众消化时间、调节节奏、掩盖连续动作或生成接缝。

人物状态来自情境，不来自服装或字面标签。穿睡衣不等于困倦；伤妆不等于始终虚弱。状态必须由前因与当场目标决定。

## 3. Blocking states

长对白或关系变化明显的场面，设计 2—3 个 blocking state。每个状态说明：

- 人物位置和朝向；
- 相对距离；
- 空间锚点；
- 谁拥有行动主动权；
- 进入下一状态的动机。

示例：门口防御 → 桌边谈判 → 窗前回避。移动必须由心理或行动触发，不能为了“画面丰富”无理由走动。

## 4. 自主世界与环境副线

场景是第二旋律。为背景写一条与地点、时间和社会关系一致的活动线：店主补货、顾客找零、路人避雨、机械继续运转。背景人物不应全部盯着主角，也不应等主角完成动作才开始下一件事。

让活动交错：主角对话时服务员处理另一位顾客；重要人物进入时，背景注意力逐步转移，而非全场瞬间同步转头。

为每个可见角色写一个镜内任务：注意谁、做什么、何时反应、反应多强。避免“大家一起笑/一起看”；改为有人捂嘴笑、有人拍腿、有人晚半拍转头、有人继续看窗外。这是画面内部的“执行导演层”，不是制作人员分工。

让入场嵌入正在发生的动作：盘子先进入画面，摄影机随动作移动，再由人物视线揭示来人。不要让全场停住等一个角色完成登场。

“加人”不是万能答案。僻静约会、秘密交易或深夜空间可以人少；热闹街区完全静止则会像布景。环境密度必须服务故事。

场景设计还要匹配人物身份。空间的尺度、秩序、材质、使用痕迹和光线共同讲述人物，而不是只满足“有桌椅、有窗户”。

跨段检查场面能量。欢乐段可用碰杯声、笑声、火焰和交错吃喝维持动能；冲突或追逐可用动作余波和环境反应承接。不要让上一段的高能量无原因坠落。

## 5. 动作、物理与危险感

复杂动作先拆状态，再描述运动：初始状态 → 发力/触发 → 中间状态 → 结果状态 → 余波。机械或道具动作必须展示关键结构变化，不能一句“拆下”“打开”跳过因果。

检查：

- 重量是否通过重心、惯性和接触反应体现；
- 人物是否与物体产生可信接触；
- 伤害是否由前置动作挣来；
- 方向、速度和遮挡是否连续；
- 动作结束后是否有身体和环境余波。

危险感来自参照物、接近临界点和后果预期，不只是速度。赛车可用机械准备、等待、倒数、对视、贴近障碍、失控征兆和观众反应逐层积累张力。

使用桥外、断面、悬崖前景或其他地理关系镜头证明危险距离。只有观众看见“离后果多近”，人物救援、退缩或冒险的动机才成立。

手持、晃动和快速切换是特定表达工具。只有人物主观失衡、现场压迫或即时危险需要时才使用；不要把它们当通用“电影感”滤镜。

## 6. 画外空间与声音

不可或不宜正面表现的内容，先确认叙事功能：观众需要知道什么、人物需要受到什么冲击。再用门缝、屏风、前景遮挡、局部身体、物件状态、屏幕反光、声音和人物反应完成表达。

画外不是省略信息，而是重新分配信息。声音必须有明确来源和空间距离；反应镜头必须让观众理解声音或局部信息对人物意味着什么。
