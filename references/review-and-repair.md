## 1. 审片顺序

先完整看一遍，不暂停列小问题。先回答：这场戏是否讲清、情绪是否抵达、观众是否知道该看谁、空间是否可信、摄影语言是否支持而非遮蔽主戏、最好的一刻在哪里。第二遍再按时间码记录问题。

记录问题时同时关联镜头/Take ID、提示词版本和实际可用区间。审片结束后把总导演的过/保/修/废裁决写入 `assets/take-prompt-log-template.csv`，连续性差异写入 `assets/continuity-ledger-template.csv`。

始终先给总判断：通过 / 有条件通过 / 需局部返工 / 需重新设计。不要从车牌、皮肤纹理或小穿帮开始堆意见。

## 2. P0/P1/P2 标准

### P0｜必须修

- 叙事信息错误或缺失；
- 人物身份、目标或关系看不懂；
- 空间、方向、视点或动作因果崩溃；
- 关键道具状态错误；
- 表演与剧情状态相反；
- 观众无法理解事件如何发生。

### P1｜优先优化

- 情绪转折无过程；
- 重要信息没有反应时间；
- 节奏单一、长对白没有调度变化；
- 背景像静止舞台；
- 权力关系、危险感或人物入口不够明确；
- 相邻生成段有明显表演或构图接缝。
- 构图、焦段、景深、运镜、速度或光线没有实现已确认的摄影命题；

### P2｜集中处理

- 局部纹理、车牌、商标和小范围背景漂移；
- 轻微光影、肤质和边缘问题；
- 不影响理解的次要连续性；
- 可统一替换的临时声音。

## 3. 保护好表演

好表演比小连续性更难重现。若整场情绪成立，只出现抱膝/放腿、服装小错或轻微轴线问题，优先尝试：

- 删掉错误区间；
- 插入主观人物反应；
- 插入环境、道具或手部特写；
- 裁切、放大或重新构图；
- 只补过渡状态；
- 用声音和画外空间连接。

只有错误破坏叙事、空间或核心表演，且无法被覆盖时，才扩大重做范围。

## 4. 最小返工路由

按顺序判断：

1. **剪辑可解**：删减、换序、延长反应、J/L cut、裁切或使用现有覆盖。
2. **单镜补拍**：补反应、关系、建立、动作关键状态、过渡或余波。
3. **小节重做**：一个 Beat 的空间、表演或动作条件整体错误。
4. **整场重设计**：场次目的、权威空间、主观视点或核心调度从根上错误。

每个修法写出保留区间、首选动作、备选动作、新资产需要和可观察验收条件。生成次数与成本只能作为 O 类估计，不得伪装成保证。

## 5. 常见症状与根因

| 症状 | 常见根因 | 首选修法 |
|---|---|---|
| 人物左右、背景漂移 | 无 master 或空间语义含糊 | 停止补近景，先重建关系图和摄影机侧 |
| 情绪突然跳变 | 两生成段无过渡状态 | 补呼吸、收身、转移注意力等桥接镜头 |
| 所有人盯主角 | 环境没有独立任务 | 给背景分配持续活动和注意力变化 |
| 台词都很快 | 未标重要信息与反应 | 为揭示点加入停顿、反应和环境静默 |
| 动作像漂浮 | 未拆状态、重量和接触 | 重写初始/发力/结果/余波，必要时拆镜 |
| 画面脏或塑料 | 低质参考传代、职责混杂 | 退回干净原图/线稿，减少参考职责 |
| 同角度跳切 | 只生成孤立近景 | 补关系、过肩、动作中切换或不同景别 |
| 模型反复犯同错 | 第二次没有人类诊断 | 分类根因并改变输入条件，而非续抽 |
| 不可直拍内容生硬 | 试图用全景证明事件 | 改用画外声、局部、遮挡和人物反应 |
| 人物像巨人、建筑像模型 | 大全景没有尺度契约 | 用门高、人车比和层高重建比例参考 |
| 群戏像僵尸或同步表演 | 只描述主角或写“大家一起” | 逐人写任务、注意力、时点和强度 |
| 人物像贴在背景上 | 面部补光固定、不响应环境 | 改用自然主义用光并写光区变化 |
| 烟、食物、门、伤妆跳变 | 未建立道具/动作状态机 | 写明初始、变化、结果并按镜头核对 |
| 台词评价无来源 | 剧本省略可见前因 | 在台词前补失误、变化或动作证据 |
| 表情精致但像 AI 演戏 | 没有对手刺激和可演动作，微表演通道过载 | 改写刺激—调整—动作链，只保留少量关键通道 |
| 反应早于台词或事件 | 未定义反应时序 | 明确刺激发生后再停顿、转移目光或改变身体任务 |
| 运镜花哨但没有张力 | 没有触发点、路径或结束构图 | 回到摄影命题，重写起点—触发—速度曲线—落点 |
| 对称构图看似工整但主次不清 | 只写“对称”，未定义中轴与重量 | 写明消失点、主体偏离规则和叙事焦点 |
| 光斑、拉丝、flare、虚焦堆叠 | 光学效果没有来源与时点 | 只保留一至两项主导效果并绑定光源/动作 |
| 相邻镜头运动断裂 | 动势、主体速度或构图重心未接续 | 对齐运动方向与剪接点，或用有动机的反向切换 |

## 6. 通过标准

一个场次可通过，当且仅当：

- 观众能说出本场发生了什么以及为何重要；
- 关键人物的目标、注意力和情绪变化可见；
- 空间与动作因果没有硬错误；
- 大全景比例和人物—环境光关系可信；
- 每个可见角色有具体任务，不出现无动机同步表演；
- 关键道具与动作状态可追踪；
- 重要信息得到足够反应时间；
- 至少有一个明确的关系或环境镜头支撑场面；
- P0 已清零；
- 剩余 P1/P2 不会反向破坏已成立的表演和结构。
